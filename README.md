## Project Overview

This project acts as a landing page to connect with me, **Sandeep Ranjan**, across various social media platforms. The design emphasizes simplicity and functionality, with all social media links opening in new browser tabs. Visitors can access my profiles without leaving the main page.

---

## Features

- **Responsive Design**: Adaptable to both desktop and mobile devices.
- **External Links**: Links to GitHub, LinkedIn, Frontend Mentor, Instagram, and LeetCode open in new tabs.
- **FontAwesome Icons**: Social media buttons are enhanced with intuitive icons.
- **Minimalistic UI**: A clean design highlighting essential information.

---

## Technologies Used

- **HTML5**: Provides the webpage structure.
- **CSS3**: Ensures visual appeal and responsive design.
- **FontAwesome**: Supplies social media icons for a modern look.

---

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sandeep7631/social-media-links.git
   ```
2. Navigate to the project folder:
   ```bash
   cd social-media-links
   ```
3. Open the `index.html` file in your browser:
   - Double-click the `index.html` file, or
   - Use any modern browser to open the file.

---

## Usage

- **Customization**: Edit the links in the `index.html` file to match your profiles.
- **Styling**: Modify the `style.css` file for a personalized look.
- **Additional Links**: Add new social media links by creating more `<a>` tags and buttons in the HTML file.
